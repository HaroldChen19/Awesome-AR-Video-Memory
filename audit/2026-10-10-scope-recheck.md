# AR video generation memory — 严格 scope 复核

复核日期：2026-10-10。时间窗：2026-09-01 至 2026-10-10。本文针对本次 PR 的新增论文；原仓库历史条目另行复核。

## 判定规则

1. **AR 依据**：论文方法或实际实验明确逐帧/逐 chunk/逐 clip 条件于历史生成视频。chunk 内扩散双向去噪允许；代理按顺序调用整段视频模型不足以证明模型为 AR。
2. **Memory 依据**：历史生成信息跨步骤保留，且后续视频生成实际读取；主分类由这条持久写读路径的载体决定。当前 clip 内上下文、临时打分特征、硬件计算复用不自动算 memory。
3. **直接贡献**：方法应直接研究 AR generator memory 的表示、写读、保留、压缩、重组或学习；普通长视频训练、外部故事/游戏规则、独立几何引擎不据此收录。
4. **角色区分**：直接研究 KV writer 学习的论文放 Learning；测试 AR generator memory 的协议/诊断放 Evaluation，不把 benchmark 作者的方法自动放 Forms。混合模型论文只收录已确认的 AR 子实验。
5. **证据不足**：标记 scope_unconfirmed 并暂缓。它表示未能从已核对段落确定 AR memory 路径，不表示证明论文没有记忆。

本次保留 **34 篇独立新论文**：30 篇方法、1 篇记忆学习、1 篇 AR 记忆诊断、2 篇仅 benchmark。另有 2 个 benchmark 与已收录方法共享论文 ID，因此 README 共新增 4 个 benchmark 条目。

相对上一版 54 篇新增，**移出 20 篇**；另将 StateAgent/StateBench 同一论文从 method 改为仅 benchmark。AlayaVista 改归 Attention-cache；HLA-WM 改为 training-free；PACC 不再声称全历史固定 query 数。

## 需要保持的边界

- **FlashForward**：正文 p.6 明确 AR planner 和 AR/chunk-causal renderer，保留跨 chunk stage K/V memory；renderer 同时读预生成的双侧 clean anchors。因此它是条件于 plan 的 AR 记忆，不能称为不含未来条件的纯在线 causal generation。
- **Honeycomb**：正文 p.6 §3.6 明确 autoregressively in overlapping chunks，并把生成 chunk 写回 HexMemory。按这一跨 chunk 生成与持久几何写读证据纳入；不是仅凭六平面表示纳入。
- **Keepsake / SMI**：分别是已确认 chunk-AR 宿主上的视觉 bank 管理；宿主存储 image 或 latent 的差别保留，不因 manager/graph 的存在分类成参数或几何世界记忆。
- **StateBench / OPIS / Causal Audit**：分别限定 MAGI-1、AR camera-driven model group、WorldMem generative arm 的 memory 实验。整篇的非 AR 模型、StateAgent 方法及 predictor/tracker 实验不一并纳入。
- **AlayaVista**：历史保存在 chunk-causal panoramic K/V，不把当前生成的全景 latent 与读取它的 perspective renderer 当作独立持久 latent bank；不宣称已经解决大位移下的全局空间记忆。
- **L2R / TourPhysics / MEWorld / CoDeR**：有关 memory 证据保留，但 AR rollout / 模型记忆接口尚未由所核对正文确立，暂缓 README 新增；后续应核对作者推理实现。
